# Weather Experiment Data Splits

Each row corresponds to one unique evaluated configuration in
`evaluation_plots/<weather>/domain_shift_summary.txt`. Sequence items use the
same canonical names and ordering as the evaluation summaries.

- **Source train:** `source_seq`.
- **Shared auxiliary:** `shared_seq`.
- **Target train:** `target_seq`, plus its frame and effective Cartesian Sedan bbox counts.
- **Target test:** `test_seq`, plus its frame and effective Cartesian Sedan bbox counts.
- Target counts exclude shared auxiliary data.
- `_first` and `_last` identify the first or last half of a sequence.
- Duplicate source-only and target-only result rows are consolidated into one configuration row.
- Group numbers follow evaluation-summary order within each weather section.
